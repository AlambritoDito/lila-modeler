## Verdicts

- **Web**: **lista** for Chrome on macOS; Safari and other browsers untested.
- **macOS arm64**: **lista con limitaciones** — unsigned and not notarized (Open Anyway on first
  launch), tested only on macOS 27.0 Apple Silicon; physical Finder double-click not exercised.

Untested and therefore unsupported: Intel Macs, Windows, Linux, macOS versions other than 27.0,
browsers other than Chrome 154, mobile editing.
