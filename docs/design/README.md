# Interface design and screenshot inventory

The [current English application gallery](en/README.md) contains real browser screenshots at
1440×900 and 1920×1080, using the default Eva-01 theme. Its reproducible capture script also
checks opening, editing, simulation, comparison, explicit saving and reload under the Pages base.
The product landing page uses only this gallery. No public deployment is implied by local capture.

application screenshots have been retired from the checkout; their immutable Git links preserve
past evidence. Neither README.es.md nor docs/es/README.md linked those images, so no redundant
Spanish application gallery is kept. The previous four files in en/ were 1280×720 JPEG data
with PNG filenames; they have been replaced with genuine PNG captures at the requested sizes.

to the same current modeling state in Eva-01, intentionally following #287's theme requirement.

## Design provenance

The historical Claude Design source is [Lila Modeler.dc.html](Lila%20Modeler.dc.html), based on
[the UI brief](../../prompts/claude-design-ui.md). Its artboards are visual references, not code to
copy. The application uses the tokens in apps/web/src/theme/. The
[dated comparison](COMPARACION-2026-09-07.md) remains historical; its old application images now
link to the immutable snapshot above. It must not be used as evidence of current release status.

The model capture includes the grouped shape palette, minimap and six validation markers.
The overlay shows the real bottleneck ranking: the leading bottleneck is always included,
followed by high-wait bottlenecks, or the first three when none is high, capped at five. Complete
results remain in the Results table. The calendar view shows the weekly editor; unsupported
minute-granularity intervals use the list editor without rounding. The scenario form follows the
scenario schema, so it need not reproduce a historical artboard's exact layout.

Current themes and their token contract are described in [THEMES.md](../THEMES.md). Numerical
results and the ranking contract are described in [RESULTS_FORMAT.md](../RESULTS_FORMAT.md).

The full [historical design decisions and component inventory](https://github.com/AlambritoDito/lila-modeler/blob/a0eb97409c91d2af5e8a6e2fae351aaa83fe13e8/docs/design/README.md)
are preserved with their original context, including Archivo typography, contrast constraints,
`fg.onAccent`, the `shadow` color token and schema-generated form rationale.
