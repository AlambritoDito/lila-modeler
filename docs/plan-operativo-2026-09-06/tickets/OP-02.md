## Trabajo

1. Crear apps/desktop con ventana y preload para la misma SPA. Añadir comandos de desarrollo y arranque compilado, coordinando manifests con A.
2. Implementar diálogos nativos y API explícita para abrir/guardar/leer proyecto. Validar entradas y limitar rutas a archivos/proyectos autorizados por diálogos; sin acceso genérico a fs desde React.
3. Elegir una estrategia de carga de producción compatible con assets, tema y Worker: protocolo local seguro o URLs relativas según lo probado. No dar por hecho que fetch de /eva-01.json funciona con file://.

## Aceptación

- [ ] npm run dev:desktop abre el editor y los diálogos nativos cancelados no producen error.
- [ ] contextIsolation y sandbox activos, nodeIntegration desactivado; preload expone solo operaciones del contrato.
- [ ] El renderer no depende de node:*; main rechaza mensajes/rutas fuera del contrato.
- [ ] Entregar a F entrada de producción y a A mecanismo de detectar el adaptador nativo.
