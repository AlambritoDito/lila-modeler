# Third-Party Notices

Inventory of the dependencies that end up **at runtime** inside the desktop artifact (the
`.dmg`/`.app` packaged by `apps/desktop`, which embeds the `apps/web` bundle). It does not include
`devDependencies` that don't ship in the bundle (for example `vite`, `typescript`, `vitest`,
`electron-builder`).

Generated by hand from `node_modules/<package>/package.json` (the `version` and `license` fields)
on 2026-09-09, over base commit `5a2711d`. Where a field was missing, "verify" is written along
with the license file found in its place, instead of inventing a value.

## Mandatory notice — bpmn.io

The BPMN editor uses [bpmn-js](https://github.com/bpmn-io/bpmn-js). Its license (MIT plus an
additional clause, see `node_modules/bpmn-js/LICENSE`) requires that the **"Powered by bpmn.io"**
watermark that bpmn-js itself draws on the canvas remain visible and not be covered by other
elements. Lila Modeler does not hide or modify it: the bottom-right corner of the modeling area is
deliberately left free (see the comment in `apps/web/src/App.tsx`, toolbar section). **Do not
remove that mark in any fork or theme customization.**

source instead of being copied.

## Out of scope for this inventory (deliberately)

- Development dependencies that don't ship in the `.dmg`: `vite`, `typescript`, `vitest`,
  `electron-builder`, `esbuild`, `tsx`, `jsdom`, `@types/*`.
- The `lila` CLI (`packages/engine/bin/lila.js`) is not part of the desktop artifact: it uses Node
  directly, not Electron. Its dependencies are the same `@lila/engine` ones already listed above
  (`zod`, `bpmn-moddle` and what the latter pulls in: `moddle`, `moddle-xml`, `min-dash`, `saxen`),
  with nothing additional.

## How this file was generated

```bash
# Version and license declared by each installed package:
python3 -c "import json; d=json.load(open('node_modules/<package>/package.json')); print(d['version'], d.get('license'))"

# Confirm that a specific package ends up in the final bundle (not just in node_modules):
npm run build -w @lila/web
grep -c '<package>' apps/web/dist/assets/index-*.js

# Chromium/Node embedded in the exact Electron version used by apps/desktop:
curl -s https://raw.githubusercontent.com/electron/electron/v44.2.0/DEPS | grep -A1 -E "chromium_version|node_version"
```

If `apps/desktop/package.json` bumps the `electron` version, repeat the last command with the new
`vX.Y.Z` tag before treating this file's Chromium/Node table as up to date.
