Lila Modeler

Open-source discrete-event simulator and modeler for BPMN processes.

Draw the process, describe a scenario — resources, calendars, costs, arrival patterns — and run it. You get Bizagi-style result tables, bottlenecks over the diagram, and an AS-IS versus TO-BE comparison with a significance marker. Apache-2.0, no account, no server: the same engine runs in the browser, on the command line and behind an MCP server.

Try the demo Source on GitHub Releases

The demo is the whole web app running in your browser: it starts with the examples/pedido restaurant process loaded, keeps your work in the browser's local storage when you choose Save project, and opens and saves .bpmn and project files as ordinary downloads. Nothing is uploaded anywhere.

What it does

One engine, three ways in. The core has no dependencies, so the numbers are the same whether you get them from a browser tab, a terminal or an agent.

  • Model

    A BPMN editor built on bpmn-js: start and end events, timers, tasks, call activities, subprocesses, XOR/OR/AND gateways, lanes and pools — with validation errors and warnings marked on the diagram as you draw.

  • Scenarios

    Resource pools with costs and shift calendars, per-element processing times and probability distributions, gateway probabilities, arrival patterns. Scenarios are plain JSON files and can extend one another.

  • Replications

    Every run is seeded and replicated, so results are reproducible and come with confidence intervals rather than a single lucky number.

  • Results

    Process, element, resource and flow tables in the layout Bizagi Modeler users already read, plus Lila's own extras: ranked bottlenecks and cost per case. Every table exports to CSV.

  • Compare AS-IS vs TO-BE

    Put two or more simulated scenarios side by side, with per-metric deltas and a marker on the differences that are significant at 95% confidence.

  • CLI and MCP

    lila validate, lila run and lila compare for scripts and CI, with JSON and CSV output — and lila mcp, an MCP server that hands the same five tools to an agent.

Simulate the benchmark in 3 commands

examples/pedido is the repo's reference benchmark: a restaurant process with a parallel branch, an approval and a timer, with the AS-IS and TO-BE scenarios already written. Clone the repo, run npm ci and npm run build, and:

1Validate the model

npx lila validate examples/pedido/model.bpmn

2Simulate the AS-IS scenario

npx lila run \
  examples/pedido/model.bpmn examples/pedido/as-is.scenario.json \
  --seed 42 --replications 3 \
  --json out/result.json --csv out/csv

3Compare AS-IS against TO-BE

npx lila compare \
  examples/pedido/model.bpmn \
  examples/pedido/as-is.scenario.json examples/pedido/to-be-3-cajeros.scenario.json \
  --seed 42 --replications 3

There is no lila package on the npm registry yet: npx resolves the workspace's own binary after npm ci and npm run build, with no registry lookup and no global install.
